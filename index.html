Lihat keranjang
Bagaimana cara top up game?
Pilih game, masukkan ID game, pilih paket, tekan Tambah, lalu periksa keranjang dan checkout. Admin akan mengonfirmasi detail pesanan melalui WhatsApp.
Apakah pembayaran langsung otomatis?
Belum. Saat ini checkout mengirim permintaan konfirmasi ke WhatsApp admin. Tunggu konfirmasi total akhir dan instruksi pembayaran sebelum membayar.
Kenapa pesanan belum masuk?
Periksa kembali ID game dan paket yang dipilih. Jika sudah mengirim pesan ke admin, tanyakan statusnya melalui WhatsApp. Jangan mengirim pembayaran ulang sebelum ada konfirmasi.
Bagaimana cara melacak pesanan?
Gunakan nomor pesanan di bagian Riwayat Pesanan. Versi ini menampilkan riwayat perubahan yang tersimpan di browser/perangkat yang sama. Pembaruan langsung dari server dan notifikasi lintas perangkat belum tersedia.
Apakah saya perlu memberikan password atau OTP?
Tidak untuk top up biasa. Jangan bagikan password atau kode OTP. Berikan hanya ID game/username yang memang diperlukan.
Bagaimana jika salah memasukkan ID?
Hubungi admin secepatnya sebelum pesanan diproses. Pastikan ID dan server (jika diperlukan) sudah benar sebelum checkout.
Bagaimana cara memakai voucher diskon?
Masukkan kode voucher pada kolom voucher di keranjang/checkout, lalu tekan Terapkan. Periksa apakah diskon muncul pada ringkasan total sebelum mengirim pesanan. Voucher yang kedaluwarsa atau nonaktif tidak dapat digunakan.
Bagaimana cara pesan jasa JB akun?
Buka bagian JB, pilih game dan keperluan (beli, jual, atau tukar tambah), lalu isi detail yang diperlukan. Tekan Konfirmasi Admin untuk mengirim rincian ke WhatsApp. Jangan berikan password atau OTP.
Bagaimana cara memesan jasa joki?
Buka bagian Joki, pilih game dan jenis layanan, lalu isi target atau detail yang diminta. Tekan Konfirmasi Admin untuk mengirim permintaan ke WhatsApp. Pastikan harga, target, dan ketentuan disepakati dengan admin terlebih dahulu.
Bagaimana cara memesan Joki Tugas?
Buka bagian Joki Tugas, pilih jenis layanan seperti editing, desain, makalah, presentasi/PPT, poster/brosur, atau layout dokumen. Isi detail tugas dan deadline jika ada, lalu tekan Konsultasi Joki Tugas via WhatsApp. Admin akan mengonfirmasi kebutuhan, estimasi waktu, dan biaya. Gunakan layanan ini sebagai bantuan belajar dan penyusunan; pastikan hasil akhir kamu pahami dan periksa sendiri.
Bagaimana cara memesan layanan sosial media?
Pilih layanan, masukkan username atau tautan akun sesuai petunjuk, lalu pilih paket. Periksa harga dan detailnya sebelum menekan Konfirmasi Admin. Jangan berikan kata sandi akun.
Kenapa voucher atau status pesanan saya tidak muncul di perangkat lain?
Versi HTML ini menyimpan banyak data di browser/perangkat yang digunakan. Data tidak otomatis tersinkron ke perangkat lain. Hubungi admin melalui WhatsApp untuk konfirmasi pesanan atau voucher.
Bagaimana menghubungi admin?
Tekan tombol Hubungi WhatsApp di Pusat Bantuan. Sertakan nomor pesanan jika ada dan jelaskan kendala secara singkat. Jangan mengirim password atau kode OTP.
